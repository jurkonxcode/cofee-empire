# Coffee Empire

Game simulasi manajemen perusahaan kopi berbasis browser (isometrik 2.5D).

## Status
Milestone: **M0 — Fondasi & Publikasi**

## Cara Menjalankan

Game di-host via GitHub Pages:
`https://<username>.github.io/<repo>/`

## Cara Mengembangkan dari HP

1. Buka repo di GitHub Web.
2. Edit file yang diinginkan.
3. Commit ke branch `main`.
4. Tunggu GitHub Pages redeploy (± 1 menit).
5. Refresh browser di HP.

## Struktur
- `index.html` — halaman & import map
- `style.css` — layout & tema
- `src/main.js` — entry point Phaser
- `src/config/` — konstanta & konfigurasi
- `src/scenes/BootScene.js` — scene placeholder M0

Lihat `ARCHITECTURE.md` dan `FILE_REGISTRY.md` untuk detail arsitektur.
